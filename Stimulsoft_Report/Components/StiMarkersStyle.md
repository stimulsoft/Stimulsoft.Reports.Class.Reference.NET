## StiMarkersStyle Enum

**Namespace:** `Stimulsoft.Report.Components`

Enumeration which sets a style of markers of the component in the designer.

### Members

| Member | Value | Description |
| --- | --- | --- |
| **None** |  | No markers visible around the component. |
| **Corners** |  | Corners of the component are visible as markers of its size. |
| **DashedRectangle** |  | Markers represents by the dashed rectangle. |
