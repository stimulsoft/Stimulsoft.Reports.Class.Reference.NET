## StiFooterMarkerContainer Class

**Namespace:** `Stimulsoft.Report.Engine`

A class describes a container which is the marker. This container is added into the output stream for identification the position of the FooterBand's in the end of a list. This is necessary because these bands are output before the list and they should be replaced into the right place.
